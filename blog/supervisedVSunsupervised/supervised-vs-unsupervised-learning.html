Supervised learning vs. unsupervised learning

Two major ways machines learn from data — one learns with answers, the other discovers patterns without them.

Chanupa Deshan · September 5, 2026 · 8 min read

A beginner-friendly field note on machine learning foundations.
THE CORE IDEA

Supervised learning learns from data that includes the correct answers. Unsupervised learning looks for useful patterns when those answers are not provided.

01The basic idea

Machine learning is about teaching computers to learn patterns from data. But not every machine learning problem is solved in the same way.

Sometimes we already know the correct answers and want a model to learn from them. Other times, we only have data and want the computer to discover interesting patterns by itself.

This gives us two important types of machine learning:

  • Supervised Learning
  • Unsupervised Learning

The easiest way to remember the difference is:

Supervised learning learns with answers. Unsupervised learning looks for patterns without answers.

Imagine that a bank has thousands of previous transactions. Some transactions are already marked as Fraud or Not Fraud.

Transaction data
      ↓
Known labels: Fraud / Not Fraud
      ↓
Train a model
      ↓
Predict whether a new transaction is fraudulent

This is supervised learning because the model is given the correct answers during training.

Now imagine the same bank has thousands of customers but has never divided them into groups. The bank wants to discover different types of customers based on spending behavior.

Customer data
      ↓
No predefined customer groups
      ↓
Find similarities
      ↓
Discover customer segments

This is unsupervised learning because the algorithm tries to discover structure without predefined target labels.

02Supervised learning

In supervised learning, we train a machine learning model using labeled data.

A label is simply the answer we want the model to learn.

Consider an email spam detector:

Email Label

Here is the project reportNot Spam

The model studies many examples like these and learns patterns associated with spam and normal emails.

New Email
    ↓

    ↓
Spam / Not Spam

Features and targets

The information we give to a machine learning model is usually called features. The answer we want the model to predict is called the target or label.

For a house-price prediction model, the features might be:

  • House size
  • Number of bedrooms
  • Location
  • Number of bathrooms
  • Age of the house

The target would be the house price.

Simple house-price dataset
Size Bedrooms Location Price

The model tries to learn how the input features are related to the target. It can then estimate the price of a house it has never seen before.

03Two main types of supervised learning

Classification

Classification means predicting a category.

Email       → Spam / Not Spam
Transaction → Fraud / Not Fraud
Image       → Cat / Dog
Customer    → Will Leave / Will Stay
Test Result → Positive / Negative

Common classification algorithms include:

  • Logistic Regression
  • Decision Trees
  • Random Forest
  • K-Nearest Neighbors
  • Support Vector Machines
  • Naive Bayes
  • Neural Networks

For example, a Logistic Regression model might calculate:

Probability of Fraud = 0.87

Decision threshold = 0.50

0.87 > 0.50

Prediction → Fraud

Regression

Regression means predicting a number or continuous value.

House price          → Rs. 35,000,000
Tomorrow's temperature → 29.5°C
Delivery time        → 42 minutes
Monthly sales        → Rs. 1,250,000

One of the simplest regression algorithms is Linear Regression. A model might learn that larger houses generally have higher prices and use that relationship to estimate the value of a new house.

04How does supervised learning learn?

Suppose we want to train a model to detect fraudulent transactions.

We first give it previous examples:

Transaction 1 → Fraud
Transaction 2 → Legitimate
Transaction 3 → Legitimate
Transaction 4 → Fraud
...

The model makes predictions. At the beginning, many predictions may be wrong.

The learning algorithm compares the model's prediction with the actual answer, measures the error, and adjusts the model.

Training Data
     ↓
Model Makes Prediction
     ↓
Compare With Correct Answer
     ↓
Calculate Error
     ↓
Adjust Model
     ↓
Repeat

After many training steps, the goal is for the model to learn patterns that also work on new data.

A good machine learning model should not simply memorize its training examples. It should make useful predictions for data it has never seen before. This is called generalization.

05Unsupervised learning

Unsupervised learning works differently. We give the algorithm data, but we do not provide the answers or target labels we want it to predict.

Imagine that an online store has information about 10,000 customers, including:

  • Age
  • Monthly spending
  • Number of purchases
  • Average order value
  • Products viewed

But the store does not already have labels such as:

Premium Customer
Regular Customer
Occasional Customer

An unsupervised learning algorithm can examine the data and try to find natural patterns.

It might discover groups such as:

Cluster 1
Young customers who purchase frequently

Cluster 2
Customers who rarely purchase but spend large amounts

Cluster 3
Regular customers with moderate spending

The important difference is that nobody told the algorithm what these groups should be. It discovered the structure from the data.

06Clustering

One of the most common unsupervised learning tasks is clustering.

Clustering means grouping similar data points together.

Suppose we have customers described by two features:

  • Annual income
  • Annual spending

Customers with similar behavior may appear close to one another. A clustering algorithm can identify these groups.

One popular clustering algorithm is K-Means Clustering.

Customer Data
      ↓
Find Similar Customers
      ↓
Create Groups
      ↓
Analyze Those Groups

Clustering can be useful for:

  • Customer segmentation
  • User behavior analysis
  • Product grouping
  • Document grouping
  • Exploring patterns in large datasets

However, the algorithm does not automatically understand what a cluster means. If K-Means creates a group of customers with high spending, a human analyst might decide to call that group High-value customers.

That meaning comes from human interpretation, not from the algorithm itself.

07Dimensionality reduction

Another common unsupervised learning task is dimensionality reduction.

Imagine a dataset with 100 features. Working with all 100 may be difficult, and some features may contain similar information.

Dimensionality reduction tries to represent the data using fewer dimensions while keeping as much useful information as possible.

One popular technique is Principal Component Analysis (PCA).

100 Features
     ↓
PCA
     ↓
10 Components

This can help with:

  • Visualizing complex datasets
  • Reducing dataset complexity
  • Speeding up some machine learning tasks
  • Finding important patterns in high-dimensional data

A streaming-platform example

Imagine a streaming platform similar to Netflix.

If the platform already knows whether users liked or disliked particular movies, it could train a model to predict:

Will this user like this movie?

Yes / No

That is a supervised learning problem because previous answers are available.

But suppose the platform wants to discover different viewing behaviors from data such as:

  • Movies watched
  • Genres watched
  • Watch time
  • Viewing frequency

An algorithm might discover groups such as action-movie fans, weekend-only viewers, documentary viewers, or heavy streaming users.

That is unsupervised learning because those groups were not provided beforehand.

09Which one should you use?

Ask yourself one important question:

Do I already know what I want the model to predict?

If the answer is yes, and you have historical examples containing that answer, supervised learning is usually a good starting point.

Examples include:

  • Predict fraud
  • Predict house prices
  • Predict customer churn
  • Classify images
  • Detect spam

If you do not have target labels and instead want to explore the data, unsupervised learning may be more appropriate.

Examples include:

  • Find customer groups
  • Discover unusual behavior
  • Group similar documents
  • Understand hidden patterns
  • Reduce dataset dimensions

10Can we use both?

Yes. Supervised and unsupervised learning are not competitors. They can be used together.

Imagine a company with thousands of customers.

First, it could use K-Means clustering to discover different customer groups:

Customer Data
      ↓
K-Means
      ↓
Customer Segments

Later, the company could collect information about which customers stopped using the service and train a Logistic Regression model to predict customer churn:

Customer Features
      ↓
Logistic Regression
      ↓
Churn / Not Churn

Real machine learning systems often combine different techniques depending on the problem.

A common misunderstanding

A common beginner mistake is thinking that supervised learning is better than unsupervised learning.

They simply solve different kinds of problems.

If you need to predict whether a transaction is fraudulent and already have labeled fraud examples, supervised learning makes sense.

If you have millions of transactions but no fraud labels and want to explore unusual behavior, unsupervised techniques may help you discover interesting patterns.

The right approach depends on:

  • The problem you are trying to solve
  • The data you have available
  • The output you want from the system

11Final thoughts

The most important difference between supervised and unsupervised learning is simple.

Supervised learning learns from data that includes known answers.

Unsupervised learning works with data without predefined answers and tries to discover useful structure.

Supervised learning commonly handles classification and regression, while unsupervised learning commonly handles clustering and dimensionality reduction.

Before selecting an algorithm, ask:

What am I trying to predict or discover?

Then ask:

Do I already have the correct answers in my dataset?

Those two questions will usually tell you whether you are dealing with supervised or unsupervised learning.
